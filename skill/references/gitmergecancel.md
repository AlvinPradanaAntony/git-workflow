# gitmergecancel

Read `references/common.md` before acting. Follow the user's explicit scope and this command's mutation boundary.

Require exactly one of `--keep` or `--abort`. For keep accept `--to staged|changes` (changes). Reject --to with abort. Require actual merge-in-progress state; if merge already committed use gitundo with verified parent, and for a completed fast-forward inspect reflog and use gitreset with an explicit verified target. Never infer a reset target solely from stale ORIG_HEAD. A rebase/cherry-pick/revert is not a merge.
Before clearing state, record HEAD, MERGE_HEAD parents, merge/autostash metadata, index and relevant working files in the verified local snapshot required by common rules. Explain keep produces ordinary changes; a subsequent ordinary commit will not record the other merge parent. If the user explicitly requested keep with this documented meaning, do not repeatedly ask.
- `--keep --to staged`: require no unmerged index entries/conflict markers. Use merge --quit to clear merge state while retaining the index/worktree. Keep existing staged resolution exactly; do not absorb unrelated unstaged hunks. If requested merge edits are still unstaged, list them and obtain selection before staging. Report what remains unstaged.
- `--keep --to changes`: preserve the current files, quit merge then mixed-reset the index to the SAME verified HEAD. Clear unmerged index entries without pretending content conflicts were resolved. Conflict markers, binary choices and eligible new files remain for manual review; enumerate unresolved content and do not stage/commit it. Confirm worktree contents match the snapshot, accounting for previously untracked files/deletions.
- `--abort`: show that merge resolutions/edits since merge began can be lost. After approval of that concrete loss if needed, run merge --abort to attempt pre-merge restoration. If it fails, stop and preserve state; no fallback hard reset. Preexisting uncommitted work is not guaranteed reconstructable.
Handle MERGE_AUTOSTASH explicitly: quit saves it to stash rather than applying it; report its ID/location and do not auto-apply. Abort may apply it and cause conflicts; verify and report the resulting state. Never pop/drop a stash or claim an exact pre-merge restoration without verification. No commit or push.
